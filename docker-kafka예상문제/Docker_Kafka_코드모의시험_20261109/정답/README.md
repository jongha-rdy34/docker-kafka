# 정답 실행 폴더

이 폴더는 응시용과 같은 공통 환경·데이터·실행기를 갖춘 완성본입니다. 응시용과 동시에 실행하지 마세요. 동일한 dk-mock 프로젝트와 컨테이너 이름을 사용합니다.

먼저 이 폴더의 실행안내.md에서 환경·명령·초기화 안내를 읽으세요. 이 폴더에서 터미널을 열면 같은 실행 명령을 그대로 사용할 수 있습니다. 시작 파일은 덮어쓰지 않고 따로 보존되어 있습니다. 정답해설.md와 answers/에 명령과 설명이 있습니다.

PDF에서 긴 명령이 여러 줄로 보일 수 있습니다. 실행할 때는 answers/*.txt 또는 README의 한 줄 명령을 사용합니다.

자동 검사:

~~~text
docker run --rm -v "${PWD}:/exam" -w /exam dk-mock-python:1 python tests/test_contracts.py tasks
~~~

정답의 Python 함수 검증은 통과했습니다. 실제 Docker 이미지 빌드·브로커 송수신은 제작 환경의 Docker 실행 엔진이 꺼져 있어 미검증입니다. 검증보고서.md를 참고하세요.
