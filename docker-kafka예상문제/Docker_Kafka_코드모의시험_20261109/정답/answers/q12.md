# Q12 정답

1. 최대 3개가 담당하고 최소 1개가 유휴이다. 같은 그룹의 한 파티션은 안정된 할당에서 한 컨슈머만 담당한다. 파티션별 메시지 건수나 처리시간이 균등해진다는 뜻은 아니다. 다른 그룹은 독립적으로 읽을 수 있다.

2. 주어진 초기 조건에서는 offset 0~4의 5건이다. 5는 최신 끝 위치(다음에 기록될 오프셋)이지 일반적인 현재 메시지 건수가 아니다. 시작이 3이면 연속한 비압축 로그의 남은 구간은 3,4의 2건이다. 압축 등으로 오프셋에 구멍이 있으면 단순 차이도 정확한 레코드 수가 아니다.

3. 불가능하다. RF=1이면 ISR에 리더 자신만 있으며 acks=all도 별도 복제본을 만들어 주지 않는다. KRaft는 메타데이터·클러스터 관리 방식이고 데이터 복제계수와 별개다. RF-1만으로 무조건 쓰기 가용성이나 무손실을 보장할 수 없다.

4. 즉시 오류라고 할 수 없다. Java 콘솔 클라이언트의 키 없는 분배는 배치·타이밍·설정의 영향을 받는다. 소량의 균등 분산이나 특정 분포를 강제하지 않는다. kafka-python 2.0.4의 기본 키 없는 파티셔너는 가능한 파티션 중 무작위 선택이므로 Java의 sticky 설명을 그대로 적용하면 안 된다. 같은 키도 파티션 수·직렬화·파티셔너가 유지된다는 조건이 필요하다.
