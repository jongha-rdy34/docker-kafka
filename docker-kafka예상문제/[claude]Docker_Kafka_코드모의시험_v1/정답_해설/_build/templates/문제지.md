## Q01. 컨테이너 안에서 로그 정리하기 (10점)

**수정 파일**: `q01/run.sh`

김싸피는 배달 서버 로그 `q01/data/server.log` 를 정리하는 셸 스크립트를 만들고 있습니다. 호스트에 도구를 설치하지 않고 **alpine 컨테이너 안에서** 실행합니다.

```bash
# 응시용 폴더에서 실행 (q01 폴더를 컨테이너의 /lab 으로 연결)
docker run --rm -v "$(pwd)/q01:/lab" -w /lab alpine:3.20 sh run.sh
```

**요구사항**
1. [1] `DATE` 변수에 오늘 날짜를 `YYYYMMDD` 로 저장합니다. 이 줄에는 **오류가 1개** 있습니다.
2. [2] `report_YYYYMMDD/logs`, `report_YYYYMMDD/backup` 을 한 번에 만듭니다. 이미 있어도 오류가 나면 안 됩니다.
3. [3] 대문자 `ERROR` 가 들어간 줄 → `logs/error.log`
4. [4] **대소문자 구분 없이** `disk` 가 들어간 줄 → `logs/disk.log`
5. [5] `error.log` 를 정렬하고 중복을 제거 → `logs/error_unique.log`
6. [6] 원본 상위 3줄 → `logs/head.txt`
7. [7] `error_unique.log` 를 `backup/` 에 **복사**합니다.
8. [8] `level_1`~`level_3` 디렉토리와 각 `README.txt`(`This is level_X directory.`)를 반복문으로 만듭니다.
9. [9] `summary.txt` 첫 줄은 새로 쓰고, 다음 줄부터는 이어 붙입니다.
10. [10] `deploy.sh` 에 소유자 `rwx`, 그룹 `r-x`, 기타 권한 없음을 **숫자 방식**으로 줍니다.
11. 스크립트를 **두 번 실행해도** 결과 파일 내용이 같아야 합니다(누적 금지).

**예상 결과**(`summary.txt`, 날짜는 실행일)
```
date: 20261109
error_unique: 2
disk: 4
```
`logs/error_unique.log` 는 `[ERROR] Disk quota exceeded`, `[ERROR] Payment timeout` 두 줄이고, `perm.txt` 는 `-rwxr-x---` 입니다.

**배점**: [1] 오류 수정 2 / [2]~[7] 명령 4 / [8]~[9] 리다이렉션·반복 2 / [10] 권한 2
