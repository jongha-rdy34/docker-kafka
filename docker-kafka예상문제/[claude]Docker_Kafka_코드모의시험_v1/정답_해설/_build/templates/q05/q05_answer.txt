# Q05 Docker Compose 멀티 컨테이너 (10점) — 명령 부분
# 모든 명령은 q05 폴더 안에서 실행합니다.

# [1] 두 서비스를 백그라운드로 실행
⟪A:docker compose up -d⟫

# [2] Compose 서비스 상태 확인
⟪A:docker compose ps⟫

# [3] api 컨테이너에서 web 서비스로 ping 3회
docker compose exec api ⟪A:ping -c 3 web⟫

# [4] api 컨테이너(alpine)에 curl 설치
docker compose exec api ⟪A:apk add curl⟫

# [5] api 컨테이너에서 web 서비스로 HTTP 요청
docker compose exec api ⟪A:curl http://web⟫

# [6] 호스트에서 웹 페이지 확인
curl http://localhost:⟪A:8081⟫

# [7] 컨테이너와 네트워크 정리
⟪A:docker compose down⟫

# [8] [5] 대신 docker compose exec api curl http://localhost:8081 을 실행하면 어떻게 되는지 이유와 함께 쓰세요.
답: ⟪A:실패한다(연결 거부). api 컨테이너 안의 localhost는 api 컨테이너 자신이고, 8081은 호스트 PC에 열린 포트다. 같은 Compose 네트워크 안에서는 서비스 이름과 컨테이너 포트(web:80, 즉 http://web)로 접근해야 한다.⟫
