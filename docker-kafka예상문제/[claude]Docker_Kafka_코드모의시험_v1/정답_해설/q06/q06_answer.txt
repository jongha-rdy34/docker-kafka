# Q06 Kafka 토픽 관리 명령 (10점)
# 모든 명령은 kafka-docker 폴더에서 docker compose exec kafka ... 형태로 작성합니다. (.sh, bin/ 사용 금지)

# [1] Kafka 컨테이너를 백그라운드로 실행하고 상태(STATUS Up) 확인
docker compose up -d
docker compose ps

# [2] delivery-status 토픽 생성: 파티션 3개, 복제 계수 1
docker compose exec kafka kafka-topics --create --topic delivery-status --bootstrap-server localhost:9092 --partitions 3 --replication-factor 1

# [3] 토픽 목록 조회
docker compose exec kafka kafka-topics --list --bootstrap-server localhost:9092

# [4] delivery-status 상세 정보(파티션·Leader·Replicas·Isr) 조회
docker compose exec kafka kafka-topics --describe --topic delivery-status --bootstrap-server localhost:9092

# [5] delivery-status 메시지 보존 기간을 30분으로 변경
docker compose exec kafka kafka-configs --alter --topic delivery-status --bootstrap-server localhost:9092 --add-config retention.ms=1800000

# [6] 변경된 토픽 설정 조회
docker compose exec kafka kafka-configs --describe --topic delivery-status --bootstrap-server localhost:9092

# [7] 삭제 연습용 delivery-temp 토픽(파티션 1, 복제 계수 1)을 만든 뒤 삭제하고, 목록에서 사라졌는지 확인
docker compose exec kafka kafka-topics --create --topic delivery-temp --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
docker compose exec kafka kafka-topics --delete --topic delivery-temp --bootstrap-server localhost:9092
docker compose exec kafka kafka-topics --list --bootstrap-server localhost:9092

# [8] 디버깅: 아래 (A)~(D)는 모두 의도대로 동작하지 않습니다. 원인을 한 줄로 쓰고 수정한 명령을 쓰세요.
# (A) 의도: delivery-log 토픽을 파티션 2개, 복제 계수 1로 생성
./bin/kafka-topics.sh --create --topic delivery-log --bootstrap-server localhost:9092 --patitions 2 --replication-factor 1
원인: 시험 환경은 Docker 기반이라 ./bin/*.sh 대신 docker compose exec kafka kafka-topics 를 써야 하고, 옵션 철자 --patitions 가 틀렸다(--partitions).
수정: docker compose exec kafka kafka-topics --create --topic delivery-log --bootstrap-server localhost:9092 --partitions 2 --replication-factor 1

# (B) 의도: delivery-status 토픽만 상세 조회
docker compose exec kafka kafka-topics --describe delivery-status --bootstrap-server localhost:9092
원인: 토픽 이름 앞에 --topic 옵션이 없다. 오류 없이 실행되지만 이름이 무시되어 delivery-status만이 아니라 전체 토픽이 조회된다.
수정: docker compose exec kafka kafka-topics --describe --topic delivery-status --bootstrap-server localhost:9092

# (C) 의도: delivery-replica 토픽 생성
docker compose exec kafka kafka-topics --create --topic delivery-replica --bootstrap-server localhost:9092 --partitions 1 --replication-factor 3
원인: 브로커가 1개뿐인데 복제 계수를 3으로 지정했다. 복제 계수는 등록된 브로커 수보다 클 수 없다("only 1 broker(s) are registered" 오류).
수정: docker compose exec kafka kafka-topics --create --topic delivery-replica --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1

# (D) 의도: delivery-status 보존 기간을 10분으로 변경
docker compose exec kafka kafka-topics --alter --topic delivery-status --bootstrap-server localhost:9092 --add-config retention.ms=600000
원인: 토픽 설정(retention.ms) 변경은 kafka-topics가 아니라 kafka-configs로 한다. kafka-topics에는 --add-config 옵션이 없다.
수정: docker compose exec kafka kafka-configs --alter --topic delivery-status --bootstrap-server localhost:9092 --add-config retention.ms=600000
