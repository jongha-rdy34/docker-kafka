## 확인하지 못한 것 / 가정

- **실제 시험 환경**: 공지의 Setup.exe가 만드는 `~/kafka-docker/docker-compose.yml` 내용은 보지 못했음(설치하지 말라는 요청). 서비스 이름 `kafka`, cp-kafka 7.6.1, 9092, KRaft라는 공지·치트시트 조건으로 대체 파일을 만들었음. 실제 파일의 환경변수(예: auto.create.topics, advertised listener)가 다르면 콘솔 프로듀서로 없는 토픽에 보내는 동작 등이 달라질 수 있음.
- **WSL 그대로의 실행**: 검증은 Windows의 Docker Desktop에서 했음. WSL 우분투 셸에서 `$(pwd)` 바인드 마운트 실행은 같은 방식이지만 직접 실행하지는 않았음.
- **대화형 입력**: `-it`, `docker start -ai`, 콘솔 프로듀서 타이핑은 `-dit`+`exec`, `exec -T < 파일` 로 같은 동작을 재현해 확인. 손으로 한 줄씩 입력할 때는 키 없는 메시지의 파티션이 실측과 다를 수 있음(문제지에 명시).
- **Jupyter 실행**: 노트북은 코드 셀을 순서대로 이어 붙여 python으로 실행해 확인(Jupyter 커널로 실행하지는 않음). 셀 간 변수 의존은 순서대로 실행하는 한 같음.
- **Q01 `perm.txt`**: 권한 실습을 컨테이너 내부 `/tmp` 에서 하도록 설계(Windows 바인드 마운트는 chmod가 반영되지 않기 때문).
- 배점·시간·제출 규칙은 출제자 가정. 실제 시험의 문항 수·형식(손으로 쓰는 답안인지, 실행 결과 캡처인지 등)은 공지에서 확인되지 않음.
- 치트시트 PDF는 한글 텍스트가 추출되지 않아 명령·영문·구성 위주로 읽었음.
