## 기존 월말평가 형식 참고

`월말평가(코드기반)/agent.md` 의 기존 시험(DB·Django·알고리즘·AI)과 Docker/Kafka 시험은 형식이 다릅니다. 아래만 참고했고, 배점·시간은 그대로 가져오지 않았습니다.

- DB 시험: 완성형과 **디버깅형 혼합**, 파일별 답안 작성 → Q06 [8], 각 문항의 `[오류 수정]` 줄
- Django 시험: 지정 파일만 수정, 미완성 코드로 실행이 막히지 않게, 실습 + 서술형 배점 분리 → 제출 규칙, Q10
- 알고리즘 시험: 예시 입출력 명시, 경계조건 → 각 문항의 예상 결과, 재실행·빈 메시지·해시 충돌 같은 경계
- Docker/Kafka 실습의 실제 수업 형식(prob.md 명령 빈칸, ipynb `___`)을 가장 우선했습니다.
