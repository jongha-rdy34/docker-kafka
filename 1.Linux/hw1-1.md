김싸피는 날짜 기반의 정리된 디렉토리 구조를 자동으로 생성하는 스크립트를 만들어야 합니다. 
각 날짜마다 level_1, level_2, level_3이라는 이름의 하위 디렉토리를 만들고, 
각 폴더에는 "This is level_X directory."라는 텍스트가 들어간 
README.txt 파일을 자동으로 생성해야 합니다.

| 절차     
1. 오늘 날짜를 YYYYMMDD 형식으로 저장한다.
2. /home/ssafy/assignment1/YYYYMMDD 경로 아래에 
level_1, level_2, level_3 디렉토리를 생성한다.
3. 각 디렉토리에 README.txt를 만들고, 해당 디렉토리명을 포함한 문장을 작성한다.
4. tree 명령어로 전체 디렉토리 구조를 확인한다.
5. cat 명령어로 각 README.txt 내용을 확인한다.
  
요구사항
date 명령어를 사용하여 날짜 문자열을 변수로 저장할 것
mkdir -p 명령어를 사용하여 디렉토리를 생성할 것
for 문을 이용하여 반복 처리할 것
echo와 > 연산자를 사용해 README.txt를 생성할 것
tree와 cat 명령어로 결과를 확인할 것
