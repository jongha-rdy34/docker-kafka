[문제]
절차     
1. /home/ssafy 경로로 이동한다.
2. project 디렉토리를 생성하고 logs, backup, scripts 하위 디렉토리를 만든다.
3. 디렉토리 구조를 cd, ls -l, tree 등을 활용해 확인한다.
4. sample.txt 파일을 생성한 뒤, logs로 이동시키고 backup으로 복사한다.  

요구사항
mkdir -p를 사용하여 중첩 디렉토리를 생성해야 한다.
ls -l, tree 명령어를 이용해 디렉토리 구조를 확인해야 한다.
mv와 cp 명령어를 사용하여 파일을 이동 및 복사해야 한다.
디렉토리 구조는 /home/ssafy/project/logs, backup, scripts 형태여야 한다.
