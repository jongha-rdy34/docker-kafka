| 절차     
1. 테스트용 로그 파일 system.log를 생성한다.

system.log
[INFO] Start process
[ERROR] Disk read failure
[WARNING] Memory usage high
[INFO] Normal operation
[ERROR] Network timeout
[WARNING] CPU temperature warning

2. 오늘 날짜를 YYYYMMDD 형식으로 저장한다.
3. backup_날짜 형식의 디렉토리를 생성한다.
4. grep 명령어로 "ERROR", "WARNING" 로그를 추출하여 각각 error.log, warning.log로 저장한다.
5. log_summary.txt 파일에 날짜, 키워드별 로그 내용을 정리한다.
6. 결과를 cat 명령어로 확인한다.  

요구사항
system.log는 실습 내에서 직접 생성할 것
날짜 기반 디렉토리를 변수로 구성할 것
각 로그 추출 결과를 별도 파일로 저장할 것
log_summary.txt 파일을 통해 요약 내용을 저장할 것
cat 명령어로 log_summary.txt 내용을 출력할 것
