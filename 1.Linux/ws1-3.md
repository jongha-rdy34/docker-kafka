[문제]
| 절차     
1. 실습용 로그 파일(system.log)을 생성한다.

system.log
[INFO] System boot complete
[ERROR] Failed to mount disk
[WARNING] CPU temperature high
[ERROR] Disk read error
[INFO] User login
[ERROR] Disk write error
[INFO] Shutdown initiated
[Disk] Disk scan complete

2. grep 명령어를 사용하여 "ERROR"와 "Disk"가 포함된 줄을 각각 추출한다.
3. head 명령어로 결과 파일의 상위 5줄을 확인한다.
4. 추출한 로그들을 sort + uniq 명령어로 정렬하고 중복 제거한 뒤 저장한다.
5. 최종 결과를 cat 명령어로 출력한다.  

요구사항
system.log 파일은 실습 내에서 직접 생성할 것
grep으로 추출한 결과를 각각 error_logs.txt, disk_logs.txt로 저장할 것
head 명령어를 통해 로그의 앞부분을 미리 확인할 것
sort | uniq를 통해 중복 없이 정렬된 결과를 error_sorted.txt, disk_sorted.txt에 저장할 것
cat 명령어로 최종 결과 파일을 확인할 것.
