| 절차     
1. ps 명령어로 현재 사용자 기준 실행 중인 프로세스를 조회한다.
2. top 명령어로 실시간 시스템 상태를 확인한다.
3. 테스트용 sleep 프로세스를 생성한다.
4. sleep 프로세스의 PID를 확인하고 종료한다.
5. df 명령어로 디스크 사용량을 확인한다.
6. free 명령어로 메모리 사용량을 확인한다.  

요구사항
ps -u $(whoami) 명령어를 사용할 것
sleep 명령어로 테스트용 프로세스를 직접 생성할 것
grep으로 sleep 프로세스를 찾아 PID를 얻을 것
kill 명령어를 사용해 해당 프로세스를 종료할 것
df -h, free -h 명령어로 자원 상태를 점검할 것
