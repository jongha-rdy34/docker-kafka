| 학습방향
김싸피는 웹 서버와 API 서버가 같은 Docker Compose 환경에서 서로 통신할 수 있는지 
확인해야 한다. 
이를 위해 nginx 기반 web 컨테이너와 alpine 기반 api 컨테이너를 
하나의 docker-compose.yml로 실행하고, 
api 컨테이너 내부에서 web 서비스로 ping 및 HTTP 요청을 보내 네트워크 통신을 검증한다.

요구사항
1. docker-compose.yml에 web 서비스를 정의하고 nginx 이미지를 사용하도록 작성하세요.
2. web 서비스의 컨테이너 이름을 web으로 지정하고, 
	호스트 8080 포트를 컨테이너 80 포트에 연결하세요.
3. docker-compose.yml에 api 서비스를 정의하고 alpine 이미지를 사용하도록 작성하세요.
4. api 서비스의 컨테이너 이름을 api로 지정하고, sleep infinity 명령으로 
	컨테이너가 종료되지 않게 설정하세요.
5. docker compose up -d 명령으로 두 컨테이너를 백그라운드에서 실행하세요.
6. docker compose exec api ping web 명령으로 api 컨테이너에서 
		web 컨테이너로의 네트워크 연결을 확인하세요.
7. api 컨테이너에 curl을 설치한 뒤 docker compose exec api curl 
	http://web 명령으로 HTTP 응답을 확인하세요.
8. docker ps 명령으로 실행 중인 컨테이너 상태를 확인하세요.
