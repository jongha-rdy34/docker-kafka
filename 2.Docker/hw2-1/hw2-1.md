[문제]
| 절차     
1. flask-app 디렉토리를 생성하고 이동한다.
2. 해당 디렉토리에 app.py를 작성한다.
3. 필요한 패키지를 명시한 requirements.txt 파일을 작성한다.
4. Dockerfile을 구성하여 flask-docker-app이라는 이름의 이미지를 만든다.
5. docker run 명령어로 컨테이너를 실행하고 5000 포트를 외부로 노출시킨다.  

요구사항
Flask 앱은 "/" 경로에서 "Hello, Dockerized Flask!" 문장을 출력해야 함
Dockerfile은 requirements.txt를 참조하여 의존성 설치 및 앱 실행 구성
컨테이너 실행 시 외부 5000 포트를 컨테이너의 5000 포트와 연결할 것
