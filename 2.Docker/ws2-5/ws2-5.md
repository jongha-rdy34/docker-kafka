[문제]
| 절차     
1. 실습 디렉토리와 index.html 파일을 생성한다.
2. nginx:alpine 이미지를 사용하는 docker-compose.yml 파일을 작성한다.
3. docker compose up 명령어로 웹 서버를 실행하고, http://localhost:8080 으로 접속한다.
4. 실습 후 docker compose down으로 컨테이너를 정리한다.  

요구사항
index.html에는 "Hello Docker Compose" 내용 포함
포트는 8080으로 지정
nginx 이미지 사용 및 volume 설정 포함
