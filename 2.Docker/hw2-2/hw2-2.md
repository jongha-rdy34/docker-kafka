[문제]
| 절차     
1. Python으로 로그 수집기(watch_log.py) 파일을 받아 올바른 디렉토리에 위치한다.
2. Dockerfile을 작성하여 컨테이너 이미지를 만든다.
3. 도커 컨테이너 실행 시 볼륨 마운트를 통해 호스트의 app.log 파일을 연결한다.
4. 로그 파일에 새로운 내용이 추가되었을 때 컨테이너 콘솔에서 확인한다.  

요구사항
Python 스크립트는 파일을 계속 읽어야 하며, 새로운 라인이 추가되면 출력해야 함
도커 실행 시 -v 옵션으로 볼륨 마운트 설정 필수
echo 명령어로 로그를 추가하여 실시간 반응 확인
