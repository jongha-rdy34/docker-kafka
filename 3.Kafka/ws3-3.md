[문제]
요구사항
1.		새로운 토픽을 생성하세요.
○   다음 명령어를 사용하여 test3-topic이라는 이름의 토픽을 생성합니다.
	■   bin/kafka-topics.sh --create --topic test3-topic --bootstrap-server localhost:9092
	 --partitions 3 --replication-factor 1
	■   --partitions 3: 해당 토픽을 3개의 파티션으로 생성
	■   --replication-factor 1: 복제본을 하나만 유지
	
2.	생성된 토픽의 상세 정보를 확인하세요.
○   생성된 토픽의 설정 및 상태를 확인합니다.
○   토픽의 파티션 개수, 리더, 복제본 및 ISR 정보를 확인합니다.
○   Leader: 해당 파티션을 담당하는 브로커
○   Replicas: 복제본이 존재하는 브로커 목록
○   ISR: 현재 정상 동기화된 복제본
○   실행 결과를 캡쳐하여 제출하세요.
○   예시 사진을 첨부해두었습니다.

3.	토픽 설정을 변경하세요.
○   특정 토픽의 설정 값을 변경할 수 있습니다. 예를 들어, 메시지 보존 기간을 변경하려면
	■   bin/kafka-configs.sh --alter --topic test3-topic --bootstrap-server localhost:9092 
	--add-config retention.ms=600000
	■   retention.ms=600000: 메시지를 10분 동안 유지 (600,000 밀리초)
	
4.	토픽을 삭제하세요.
○   불필요한 토픽을 삭제하려면 다음 명령어를 실행합니다.
	■   bin/kafka-topics.sh --delete --topic test3-topic --bootstrap-server localhost:9092
○   주의: 기본적으로 Kafka는 토픽 삭제가 비활성화되어 있을 수 있으므로, 
	server.properties 파일에서 delete.topic.enable=true 설정을 확인해야 합니다.
○   delete.topic.enable=true는 삭제를 ‘허용’ 하는 설정일 뿐, 즉시 삭제를 보장하지 않음
○   삭제는 비동기라서 잠시 남아있는 게 정상일 수 있으며 메타데이터 상에 남아 있을 수 있음
