[문제]
1.    세 개의 Kafka 브로커 실행하세요.
○   브로커 설정 파일 생성 및 수정
	■   기존 server.properties 파일을 복사하여 추가 브로커 설정 파일을 생성합니다.
		●   cp config/server.properties config/server-1.properties
		●   cp config/server.properties config/server-2.properties
	■   각 설정 파일을 수정합니다.
		●   config/server-1.properties
			○   broker.id=1
			○   listeners=PLAINTEXT://localhost:9093
			○   log.dirs=/tmp/kafka-logs-1
		●   config/server-2.properties
			○   broker.id=2
			○   listeners=PLAINTEXT://localhost:9094
			○   log.dirs=/tmp/kafka-logs-2
○   세 개의 브로커 실행 
	■   bin/kafka-server-start.sh config/server.properties &\
			bin/kafka-server-start.sh config/server-1.properties &\
			bin/kafka-server-start.sh config/server-2.properties &
	■   bin/kafka-server-start.sh -daemon config/server.properties와 같은 명령어도 가능
○   브로커가 정상적으로 동작하는지 확인:
	■   bin/kafka-topics.sh --list --bootstrap-server localhost:9092
	■   bin/kafka-topics.sh --list --bootstrap-server localhost:9093
	■   bin/kafka-topics.sh --list --bootstrap-server localhost:9094
	■   실행 결과를 캡쳐하여 제출하세요.
	■   예시 사진을 첨부해두었습니다.
	
2.    토픽을 생성하고 상태 확인하세요.
○   아래 명령어로 토픽 생성
	■   bin/kafka-topics.sh --create --topic test5-topic --bootstrap-server \
			localhost:9092 --partitions 1 --replication-factor 3
	■   --partitions 1: 하나의 파티션만 생성하여 실습을 단순화함.
	■   --replication-factor 3: 세 개의 브로커에서 복제본 유지.
○   생성된 토픽 상태 확인:
	■   bin/kafka-topics.sh --describe --topic test5-topic --bootstrap-server \
	localhost:9092
	■   실행 결과를 캡쳐하여 제출하세요.
	■   예시 사진을 첨부해두었습니다.
	
3.    메시지 송수신 테스트를 수행하세요.
○   프로듀서 실행:
	■   bin/kafka-console-producer.sh --topic  test5-topic --bootstrap-server \
	localhost:9092
○   메시지를 입력:
	■   Message from replicated cluster
	■   Another message
○   컨슈머 실행:
	■   bin/kafka-console-consumer.sh --topic  test5-topic --from-beginning \
	--bootstrap-server localhost:9092
