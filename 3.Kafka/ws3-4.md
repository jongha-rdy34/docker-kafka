1.		Kafka 토픽을 생성하세요.
○   이전 실습에서 토픽이 삭제되었으므로 새롭게  test4-topic을 생성합니다.
	■   bin/kafka-topics.sh --create --topic test4-topic --bootstrap-server localhost:9092 \
			--partitions 1 --replication-factor 1
	■   --partitions 1: 1개의 파티션을 가진 토픽을 생성합니다.
	■   --replication-factor 1: 복제본을 하나만 유지합니다.
○   bin/kafka-topics.sh --list --bootstrap-server localhost:9092 
		명령어로 생성된 토픽을 확인합니다.
○   실행 결과를 캡쳐하여 제출하세요.
○   예시 사진을 첨부해두었습니다.

2.	Kafka 프로듀서를 실행하여 메시지를 전송하세요.
○   Kafka 프로듀서를 실행하여  test4-topic에 메시지를 보냅니다.
	■   bin/kafka-console-producer.sh --topic  test4-topic --bootstrap-server \
	localhost:9092
○   실행 후 메시지를 입력하면  test4-topic으로 전송됩니다. 예를 들어:
	■   Hello Kafka!
	■   This is a test message.
○   입력한 메시지는 Kafka 브로커를 통해  test4-topic에 저장됩니다.

3.	Kafka 컨슈머를 실행하여 메시지를 수신하세요.
○   Kafka 컨슈머를 실행하여  test4-topic의 메시지를 읽습니다.
	■   --from-beginning 옵션을 사용하면 해당 토픽의 모든 메시지를 처음부터 읽을 수 있습니다.
○   컨슈머 실행 후 프로듀서에서 보낸 메시지가 출력되는지 확인합니다.

4.	메시지 송수신 테스트를 수행하세요.
○   프로듀서에서 추가적으로 메시지를 입력하고, 컨슈머에서 해당 메시지가 정상적으로 출력되는지
 확인합니다.
○   컨슈머 실행 창에서 추가로 입력한 메시지가 출력되어야 합니다.
○   실행 결과를 캡쳐하여 제출하세요.
○   예시 사진을 첨부해두었습니다.
○   컨슈머가 메시지를 정상적으로 받지 못하면 Kafka 브로커가 실행 중인지 확인해야 합니다.
