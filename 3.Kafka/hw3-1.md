[문제]
요구사항
1.	Docker를 활용하는 경우 그에 맞게 명령어를 변경하여 진행하면 됩니다.

2.	다중 토픽 생성
○   topic-1과 topic-2라는 이름의 두 개의 토픽을 생성합니다.
	■   docker compose exec kafka kafka-topics --create --topic topic-1 \
	--bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
	■   docker compose exec kafka kafka-topics --create --topic topic-2 \
	--bootstrap-server localhost:9092 --partitions 1 --replication-factor 1
○   docker compose exec kafka kafka-topics --list --bootstrap-server localhost:9092 \
		명령어를 실행하여 생성된 토픽을 확인합니다.
		
3. 각 토픽에 메시지 송수신 테스트
○   Topic-1에 메시지 전송:
	■   docker compose exec kafka kafka-console-producer --topic topic-1 \
	--bootstrap-server localhost:9092
○   메시지를 입력하여 전송합니다.
	■   Message to topic-1
	■   Another message for topic-1
○   Topic-2에 메시지 전송:
	■   docker compose exec kafka kafka-console-producer --topic topic-2 \
	--bootstrap-server localhost:9092 
○   메시지를 입력하여 전송합니다.
	■   Message to topic-2
	■   Another message for topic-2
	
4. 컨슈머 실행 및 특정 토픽 메시지 확인
○   Topic-1의 메시지 소비:
	■   docker compose exec kafka kafka-console-consumer --topic topic-1 --from-beginning\
	 --bootstrap-server localhost:9092
	■   Topic-1의 메시지가 정상적으로 출력되는지 확인합니다.
	■   실행 결과를 캡쳐하여 제출하세요.
○   Topic-2의 메시지 소비:
	■   docker compose exec kafka kafka-console-consumer --topic topic-2 --from-beginning\
	 --bootstrap-server localhost:9092
	■   Topic-2의 메시지가 정상적으로 출력되는지 확인합니다.
	■   실행 결과를 캡쳐하여 제출하세요.
	■   예시 사진을 첨부해두었습니다.
